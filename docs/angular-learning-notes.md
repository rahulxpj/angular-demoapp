# Angular Demo App

A basic Angular project created while learning Angular and TypeScript.

## Purpose

This project is being used to understand the structure of an Angular application
and gain hands-on experience with Angular and TypeScript.

## What I Learned

### TypeScript

- Basic TypeScript syntax
- Variables and data types
- Functions
- Classes
- Interfaces
- Imports and exports
- Understanding `.ts` files in an Angular project

### Angular

- Basic Angular project structure
- Angular components
- Templates and HTML
- TypeScript and HTML interaction
- Angular application bootstrap process
- Angular routing basics
- Understanding the `src/app` directory
- Understanding `main.ts`
- Understanding `app.ts`
- Understanding `app.html`
- Understanding `app.routes.ts`
- Understanding `app.config.ts`
